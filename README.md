# NCSA AI Bootcamp: Generative AI & Prompt Engineering

ชุดสื่อการสอนและแบบประเมินผลสำหรับหลักสูตรปัญญาประดิษฐ์ (Generative AI) เพื่อยกระดับทักษะบุคลากร

## 📂 โครงสร้างโปรเจกต์
- 📘 **DAY 2:** พื้นฐานปัญญาประดิษฐ์, หลักการทำงานของ LLMs และโครงสร้างการสั่งงานเบื้องต้น (RTCF Framework)
- 📙 **DAY 3:** เทคนิคขั้นสูง (Iterative, Chaining, Socratic), การประยุกต์ใช้รายสายอาชีพ และจริยธรรม AI
- 📝 **Assessments:** แบบทดสอบก่อนเรียน (Pre-test) และหลังเรียน (Post-test) พร้อมเฉลยและเหตุผลประกอบอย่างละเอียด

## 🚀 เนื้อหาหลัก
1. **Understanding LLMs:** เจาะลึกการทำงานของโมเดลภาษา
2. **Prompt Engineering:** เทคนิคการเขียนคำสั่งให้มีประสิทธิภาพ
3. **Professional Use Cases:** ตัวอย่างการใช้ AI ในงาน HR, Marketing, Finance, IT และ Project Management
4. **AI Ethics & Security:** การใช้งานอย่างปลอดภัยและรับผิดชอบต่อองค์กร

## 🛠 วิธีใช้งาน
- เปิดไฟล์ `.html` ผ่าน Web Browser เพื่อดูสไลด์บรรยาย
- ไฟล์ในโฟลเดอร์ `Assessments` อยู่ในรูปแบบ Markdown (.md) สามารถอ่านได้โดยตรงหรือนำไปลงในระบบทดสอบออนไลน์
