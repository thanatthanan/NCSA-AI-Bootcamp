คัมภีร์ Claude Cowork สำหรับข้าราชการ
ช่วงหลังมานี้ผมได้รับเชิญให้เข้าไปบรรยาย AI ในหน่วยงานราชการบ่อยขึ้นเรื่อยๆ บรรยากาศที่เจอเหมือนกันหมดเกือบทุกที่ คือพี่ๆ ข้าราชการอยากใช้ AI ช่วยทำงาน แต่ติดเรื่องไม่รู้ว่าจะเริ่มอย่างไร และความ sensitive ของข้อมูลประชาชน
วันนี้ผมเลยใช้เวลาช่วงบ่ายขณะมาท่องเที่ยวอยู่โตเกียว เขียนออกมาเป็นคัมภีร์ Claude Cowork สำหรับข้าราชการมาฝากกัน เพื่อให้อ่านจบแล้วเอาไปใช้ได้จริง และปลอดภัยพอที่จะใช้ในงานราชการครับ
.
.
Claude Cowork คืออะไรแบบเข้าใจง่ายๆ
Claude Cowork คือโหมดหนึ่งในแอพ Claude Desktop ที่ทำให้ Claude ลงมือทำงานบนเครื่องคอมพิวเตอร์ของเราได้จริง อ่านไฟล์ในเครื่อง สร้างไฟล์ใหม่ แก้ไขไฟล์เดิม เชื่อมกับ Gmail Google Drive Microsoft 365 ตั้งเวลาให้ทำงานอัตโนมัติ และทำงานหลายขั้นตอนต่อเนื่องโดยที่เราไม่ต้องคอยป้อนทีละคำสั่ง ลองนึกภาพว่าจ้างผู้ช่วยมาคนหนึ่งที่นั่งอยู่หน้าจอเดียวกับเรา รู้ว่าไฟล์อะไรเก็บที่โฟลเดอร์ไหน รู้รูปแบบหนังสือราชการของหน่วยงาน และทำงานแทนเราได้ทั้งงาน นั่นคือสิ่งที่ Cowork เป็นครับ
.
Claude Cowork เหมาะกับงานข้าราชการตรงไหน
1. งานเอกสารราชการที่มีรูปแบบตายตัว 
หนังสือราชการมี 6 ชนิดตามระเบียบสารบรรณ ทั้งหนังสือภายนอก หนังสือภายใน หนังสือประทับตรา หนังสือสั่งการ หนังสือประชาสัมพันธ์ และหนังสือที่เจ้าหน้าที่จัดทำขึ้นหรือรับไว้เป็นหลักฐาน 
แต่ละชนิดมีโครงสร้าง คำขึ้นต้น คำลงท้าย ระยะขอบ ฟอนต์ และการวางครุฑที่ระเบียบกำหนดไว้ชัดเจน Cowork เก่งมากในการจำรูปแบบเหล่านี้ไว้ใน Project แล้วผลิตเอกสารใหม่ที่ตรงตามระเบียบทุกครั้ง ไม่ต้องมาตั้ง margin ใหม่ ไม่ต้องค้นหาฟอนต์ Sarabun ไม่ต้องเปิดตัวอย่างเก่ามาก๊อปปี้
2. งานวิเคราะห์และสรุปเอกสารปริมาณมาก (batch processing)
ข้าราชการต้องอ่านหนังสือเวียน อ่านระเบียบใหม่ มติคณะรัฐมนตรี อ่านยุทธศาสตร์ชาติ อ่านรายงานเชิงนโยบายจากหน่วยงานในกำกับ Cowork สามารถอ่านไฟล์ทั้งโฟลเดอร์ในครั้งเดียว ดึงประเด็นสำคัญ เปรียบเทียบสาระสำคัญระหว่างฉบับเก่ากับฉบับใหม่ และสรุปออกมาเป็นบันทึกเสนอผู้บังคับบัญชาได้ในไม่กี่นาที
ส่วนเอกสารที่มีข้อมูลประชาชน เช่น คำร้อง คำขอ ข้อร้องเรียน ห้ามนำเข้า Cowork โดยเด็ดขาดครับ รายละเอียดอยู่ในส่วนข้อห้ามท้ายบทความ
3. งานที่ต้องทำซ้ำทุกสัปดาห์ทุกเดือน 
รายงานผลการดำเนินงานรายเดือน สรุปสถิติผู้มารับบริการ รายงาน KPI รายงานความก้าวหน้าโครงการ Cowork มีฟีเจอร์ Scheduled Tasks ที่ตั้งให้ทำเป็นรอบได้เลย พิมพ์คำว่า schedule นำหน้าคำสั่ง แล้วเลือกความถี่ ตั้งเสร็จก็ปล่อยให้รันไปเรื่อยๆ โดยมีข้อแม้สำคัญข้อเดียว คือเครื่องคอมต้องเปิดอยู่และ Claude Desktop ต้องเปิดอยู่ในเวลาที่ task ถึงกำหนดรัน ถ้าปิดเครื่องหรือพับฝาแล็ปทอป task จะไม่ทำงาน
.
การ Setup Claude Cowork ให้เหมาะกับงานราชการ
Prep 0: เลือกแพลนให้ถูก 
Cowork ใช้ได้บนแพลน Pro Max Team และ Enterprise ถ้าเป็นการใช้งานในระดับหน่วยงาน ผมแนะนำให้ใช้ Team หรือ Enterprise เพราะข้อมูลของเราจะไม่ถูกนำไปเทรนโมเดลโดยอัตโนมัติ ส่วนแพลน Pro กับ Max เป็น consumer account 
ตั้งแต่ปลายปี 2025 เป็นต้นมา Anthropic ใช้นโยบายว่าจะนำข้อมูลไปใช้เทรนโมเดลถ้าผู้ใช้ไม่ปิด toggle ที่ชื่อ Help improve Claude ในหน้า Settings ดังนั้นถ้าใครใช้แพลนส่วนตัวสำหรับงานราชการ ต้องเข้าไปปิด toggle นี้ทันทีก่อนใช้งาน อยู่ที่เมนู Settings เลือก Privacy แล้วปิดสวิตช์ Help improve Claude ให้กลายเป็นปิด
.
Prep 1: ติดตั้ง Claude Desktop จาก claude . com / download 
เปิดโปรแกรม login เสร็จแล้วจะเห็นแถบด้านซ้ายมีคำว่า Cowork คลิกเข้าไป จากนั้นไปที่ Projects แล้วกดเครื่องหมายบวกเพื่อสร้าง Project ใหม่ Project คือพื้นที่ทำงานแยกเฉพาะที่มีคำสั่งประจำ ไฟล์ประจำ และความจำของตัวเอง ไม่ปนกับงานอื่น

เหตุผลที่ใช้เลขนำหน้า 01 ถึง 05 คือเพื่อให้โฟลเดอร์เรียงลำดับตามขั้นตอนการทำงานเสมอบนทุกระบบปฏิบัติการ ไล่จากข้อมูลอ้างอิงไปยังขาออก เปิดเข้ามาเห็นปุ๊บก็เข้าใจ flow ทันที
ข้อสำคัญที่ต้องท่องไว้เลยคือ โฟลเดอร์ทั้งห้านี้คือพื้นที่ที่ Cowork จะมองเห็นและอ่านได้ ดังนั้นห้ามมีไฟล์ที่มีข้อมูลส่วนบุคคลของประชาชนวางอยู่ในโฟลเดอร์เหล่านี้เด็ดขาด ไม่ว่าจะเป็นคำร้อง คำขอ ข้อร้องเรียน เอกสารคดี หรือทะเบียนต่างๆ ที่ระบุตัวบุคคล เอกสารกลุ่มนี้ต้องเก็บแยกในโฟลเดอร์อื่นที่ Cowork ไม่ได้ชี้ถึง หรือเก็บในระบบปิดของหน่วยงานเท่านั้น
โฟลเดอร์ 01-ระเบียบและคู่มือ เก็บไฟล์ระเบียบสำนักนายกรัฐมนตรีว่าด้วยงานสารบรรณฉบับล่าสุด คู่มือการพิมพ์หนังสือราชการ ระเบียบเฉพาะของหน่วยงาน คู่มือการเขียนหนังสือราชการ และระเบียบที่เกี่ยวข้องกับงานของเราโดยตรง โฟลเดอร์นี้คือสมองที่ Claude จะใช้อ้างอิงทุกครั้งที่ต้องร่างเอกสาร
โฟลเดอร์ 02-แม่แบบเอกสาร เก็บไฟล์ template ของเอกสารแต่ละชนิด หนังสือภายในแบบ Word หนังสือภายนอกที่มีครุฑ บันทึกข้อความ คำสั่ง ประกาศ รายงานการประชุม TOR ทุกอย่างเป็นไฟล์เปล่าที่จัดรูปแบบไว้พร้อมแล้ว
โฟลเดอร์ 03-เอกสารที่เคยส่งออก เก็บเอกสารตัวอย่างที่เคยทำเสร็จแล้วและผ่านการอนุมัติ เอกสารพวกนี้คือตัวอย่างที่ดีที่สุดให้ Claude เรียนรู้สำนวน คำลงท้าย และระดับความเป็นทางการของหน่วยงานเรา
โฟลเดอร์ 04-งานปัจจุบัน แบ่งเป็นโฟลเดอร์ย่อยตามโครงการหรือเรื่องที่กำลังทำ เช่น งานงบประมาณ-2569 งานตรวจราชการ-มีนาคม งานประชุม-คณะกรรมการ ใช้สำหรับวางไฟล์ working ที่ Claude ต้องเข้าไปอ่านและแก้ไข
โฟลเดอร์ 05-ขาออก เป็นโฟลเดอร์ที่ให้ Claude เซฟไฟล์ที่ทำเสร็จมาวาง เพื่อให้เราตรวจก่อนส่งจริง
หลังจากสร้างโฟลเดอร์แล้ว กลับมาที่ Claude Desktop แท็บ Cowork ไปที่ Projects กดบวก เลือก Start from existing folder ตั้งชื่อ Project ว่า งานราชการประจำ จากนั้นใส่ Custom Instructions ให้ Project นี้ ตัวอย่างคำสั่งที่ผมแนะนำ
"ให้ Claude อ่านไฟล์ในโฟลเดอร์ 01-ระเบียบและคู่มือ ก่อนทุกครั้งที่ร่างเอกสารราชการ ใช้ฟอนต์ TH Sarabun PSK ขนาด 16 ตั้งระยะขอบบน 2.5 cm ขอบล่าง 2 cm ขอบซ้าย 3 cm ขอบขวา 2 cm เลขไทยใช้เลขอารบิก ยกเว้นในเอกสารที่ระเบียบกำหนดให้ใช้เลขไทย คำขึ้นต้น คำลงท้าย และสรรพนามให้เลือกตามฐานะของผู้รับตามภาคผนวกของระเบียบสารบรรณ ก่อนเริ่มร่าง ให้ถามผู้ใช้เสมอว่าเป็นหนังสือชนิดใด ใครคือผู้ลงนาม และใครคือผู้รับ ห้ามแต่งเลขที่หนังสือเอง ห้ามใส่วันที่เอง ให้เว้นว่างไว้ให้เจ้าหน้าที่สารบรรณกรอก เซฟไฟล์ที่เสร็จแล้วเป็น docx ลงโฟลเดอร์ 05-ขาออก ตั้งชื่อไฟล์ตามรูปแบบ ปีเดือนวัน-ชนิดเอกสาร-เรื่องสั้น"
จากนั้นอัปโหลดไฟล์สำคัญที่ใช้บ่อยเข้า Project เช่น โครงสร้างหน่วยงาน รายชื่อผู้บริหาร พันธกิจวิสัยทัศน์ กลุ่มผู้รับสารหลัก และรหัสประจำหน่วยงาน เพราะข้อมูลพวกนี้ Claude จะดึงมาใช้ตลอด
เมื่อสร้าง Project เสร็จ เวลาทำงานให้เปิด Cowork แล้วเลือก Project นี้ แล้วชี้โฟลเดอร์ ราชการ-Cowork เป็น working folder ของ session ทุกครั้ง
อีกขั้นที่สำคัญมากคือเลือกโหมดการอนุมัติให้เหมาะกับงานราชการ
Cowork มีสองโหมด คือ Ask before acting ที่ Claude จะหยุดถามทุกครั้งก่อนแก้ไขไฟล์ และ Act without asking ที่ทำงานต่อเนื่องโดยไม่ต้องขออนุญาต สำหรับงานราชการ ผมแนะนำให้ใช้ Ask before acting เป็นค่าเริ่มต้น ทุกครั้งที่ Claude จะแตะไฟล์เราจะเห็นและกดอนุมัติก่อน เป็นการลดความเสี่ยงที่จะมีอะไรเปลี่ยนแปลงโดยที่เราไม่รู้ครับ
.
เทคนิค Claude Cowork สำหรับข้าราชการไทย
Technic 1: ใช้ Skills เพื่อบังคับรูปแบบหนังสือราชการให้ออกมาเป๊ะทุกครั้ง 
Skills คือคู่มือเฉพาะทางที่ Claude จะเปิดอ่านอัตโนมัติเมื่อเจองานที่ตรงกับ skill นั้น เราสร้าง skill ของเราเองได้ โดยไปที่เมนู Customize เลือก Skills แล้วกดสร้างใหม่ ให้สร้าง skill ชื่อ thai-government-document แล้วเขียน SKILL.md ที่อธิบายโครงสร้างหนังสือราชการแต่ละชนิด พร้อมตัวอย่าง พร้อมข้อห้าม เช่น ห้ามใช้เครื่องหมายอัศเจรีย์ ห้ามใช้คำพูดที่ไม่เป็นทางการ ห้ามขึ้นต้นย่อหน้าด้วยคำว่าสำหรับ 
พอติดตั้งเสร็จแล้ว ทุกครั้งที่เราพิมพ์ว่าช่วยร่างหนังสือภายในให้หน่อน Claude จะเปิด skill นี้ขึ้นมาก่อนแล้วเขียนตามโครงสร้างทันที ผลลัพธ์จะนิ่งและสม่ำเสมอกว่าการให้ instructions ใน Project อย่างเดียวมาก

Technic 2: ใช้ MCP Connectors เชื่อมกับ Microsoft 365 หรือ Google Workspace ให้ดึงเอกสารและส่งเอกสารต่อได้ในที่เดียว 
ถ้าหน่วยงานใช้ Microsoft 365 เปิด connector Microsoft 365 ใน Customize แล้ว Claude จะเข้าถึง Outlook SharePoint OneDrive ได้ ตัวอย่างที่ใช้ได้ปลอดภัย ดึงอีเมลภายในที่เป็นการประสานงานระหว่างเจ้าหน้าที่ในเรื่องโครงการตรวจราชการสามสิบวันล่าสุดมาสรุปประเด็น แล้วร่างหนังสือเชิญประชุมคณะทำงานภายใน Claude จะอ่าน สรุป และร่างหนังสือให้ในชุดเดียวกัน 
ถ้าหน่วยงานใช้ Google Workspace ก็เปิด connector Gmail Google Drive Google Calendar ได้เหมือนกัน ข้อควรระวังคืออีเมลของหน่วยงานราชการมักมีเรื่องที่มีข้อมูลประชาชนปนอยู่ เช่น เรื่องร้องเรียน เรื่องขอข้อมูลข่าวสาร ก่อนสั่งให้ Claude ดึงอีเมลแบบกว้างๆ ต้องคิดให้รอบคอบว่าอีเมลที่จะถูกดึงเข้ามามีข้อมูลประชาชนหรือไม่ ทางที่ปลอดภัยคือระบุ label หรือ folder อีเมลที่จะให้ดึงให้ชัดเจน เลือกเฉพาะอีเมลภายในที่เป็นเรื่องนโยบายและการประสานงานเท่านั้นครับ
.
Technic 3: ตั้ง Scheduled Tasks สำหรับงานประจำสัปดาห์และประจำเดือน 
ตัวอย่างที่ใช้ได้จริง ตั้งให้ทุกเช้าวันจันทร์เวลาเก้าโมงเปิดโฟลเดอร์ 04-งานปัจจุบัน อ่านไฟล์ทุกตัว สรุปสถานะของแต่ละโครงการ แล้วเซฟเป็นไฟล์ briefing-วันจันทร์ ลงโฟลเดอร์ 05-ขาออก พอถึงเช้าวันจันทร์เปิดเครื่องมาก็เห็นสรุปพร้อมเข้าประชุมเลย 
อีกตัวอย่างคือทุกสิ้นเดือนวันที่ 28 เวลาห้าโมงเย็น ให้สรุปงานที่ปิดในเดือนนั้น พร้อมจำนวนหนังสือเข้า หนังสือออก และเรื่องที่ยังค้าง เซฟเป็นรายงาน ผบ บนภาพรวม 
วิธีตั้ง Scheduled Task ทำได้สองทาง ทางแรกคือพิมพ์คำว่า /schedule ตามด้วย task ที่อยากให้ทำ ทางที่สองคือคลิก Scheduled ที่แถบซ้ายแล้วสร้างใหม่ อย่าลืมข้อแม้สำคัญที่ผมพูดไปแล้ว เครื่องต้องเปิดและ Claude Desktop ต้องเปิดในเวลาที่ task รัน
ข้อควรระวังพิเศษของ Scheduled Tasks คือมันรันโดยไม่มีคนยืนเฝ้า ถ้าวันใดมีไฟล์ที่มีข้อมูลประชาชนหลุดเข้าไปในโฟลเดอร์ที่ task ตั้งให้อ่าน Claude จะอ่านโดยอัตโนมัติทันทีโดยที่เราไม่รู้ ดังนั้นโฟลเดอร์ที่ผูกกับ Scheduled Task ต้องมีกฎเหล็กว่าห้ามวางไฟล์ที่มีข้อมูลประชาชนลงไป และต้องมีรอบตรวจโฟลเดอร์ทุกสัปดาห์เพื่อยืนยันว่าไม่มีไฟล์ผิดประเภทหลุดเข้ามานะครับ
Technic 4: ใช้ Cowork อ่านชุดเอกสารใหญ่แล้วเทียบประเด็น 
เช่น เอาระเบียบฉบับใหม่ที่เพิ่งประกาศมาไว้กับฉบับเดิม สั่งให้เทียบทีละมาตรา ระบุว่าเปลี่ยนตรงไหนบ้าง และผลกระทบต่อหน่วยงานเราคืออะไร พร้อมร่างบันทึกเสนอ ผบ ให้ทราบ Cowork จะใช้ sub-agents แตกงานเป็นส่วนๆ ทำขนานกันแล้วประมวลผลรวมตอนท้าย งานนี้ถ้าทำเองใช้เวลานาน ใช้ Cowork เถอะครับ ช่วยลดเวลาได้มาก
Technic 5: ใช้ Dispatch สั่งงานจากมือถือเวลาที่อยู่นอกออฟฟิศหรือลงพื้นที่ 
Cowork มี mobile access สำหรับแพลน Pro และ Max ที่ทำให้สั่ง Claude ทำงานบนเครื่องที่ออฟฟิศจากมือถือได้ เช่น ระหว่างเดินทางไปประชุม สั่งให้เตรียมสรุปวาระให้พร้อมเปิดเครื่องมาเจอเลย หรือระหว่างลงพื้นที่ มีข้อมูลใหม่ส่งให้ Claude อัปเดตไฟล์โครงการได้ทันที
.

3 ข้อห้ามสำคัญของการใช้ Claude Cowork ในงานราชการ
1. ห้ามนำข้อมูลส่วนบุคคลของประชาชนใส่เข้า Claude Cowork ไม่ว่าแพลนใดก็ตาม ไม่ว่าจะเปิดฟีเจอร์ Zero Data Retention หรือไม่ก็ตาม 
เลขประจำตัวประชาชน ที่อยู่ เบอร์โทร เลขบัญชีธนาคาร ข้อมูลสุขภาพ ข้อมูลคดี ข้อมูลภาษี ข้อมูลเงินเดือน ข้อมูลการศึกษาของบุคคลที่ระบุตัวได้ เป็นข้อมูลส่วนบุคคลที่ได้รับการคุ้มครองตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 
หน่วยงานราชการอยู่ในฐานะผู้ควบคุมข้อมูลส่วนบุคคล มีหน้าที่ตามกฎหมายในการรักษาความปลอดภัยของข้อมูลเหล่านี้ และมีความรับผิดเฉพาะตัวหากเกิดการรั่วไหล แพลน Enterprise ของ Anthropic แม้จะรับประกันว่าจะไม่นำข้อมูลไปเทรนโมเดลและมีตัวเลือก Zero Data Retention ก็ยังหมายความว่าข้อมูลถูกส่งออกจากระบบของหน่วยงานไปประมวลผลที่ระบบของผู้ให้บริการต่างประเทศอยู่ดีครับ  
ดังนั้นในทางปฏิบัติ ให้ถือหลักไว้ก่อนว่าข้อมูลประชาชนทุกชนิด ห้ามเข้า Cowork ส่วนงานที่จำเป็นต้องประมวลผลข้อมูลประชาชนจริงๆ ให้ใช้ระบบสารสนเทศเฉพาะของหน่วยงานที่ผ่านการประเมินความปลอดภัยแล้วเท่านั้น
2. ห้ามใช้ผลลัพธ์จาก Claude เป็นเอกสารสุดท้ายโดยไม่ตรวจ Claude เก่งมากในการร่าง แต่ไม่ใช่ผู้รับผิดชอบทางกฎหมาย เอกสารราชการทุกฉบับต้องมีคนลงนามรับผิดชอบ ก่อนส่งออกต้องมีข้าราชการอ่านทบทวนทุกประโยค ตรวจชื่อบุคคล ตรวจตำแหน่ง ตรวจการอ้างอิงระเบียบและกฎหมาย 
AI สามารถแต่งชื่อระเบียบที่ไม่มีอยู่จริง สามารถอ้างมาตราที่เลขผิด สามารถสร้างตัวเลขที่ดูสมเหตุสมผลแต่ไม่ตรงกับข้อมูลจริง ความรับผิดชอบยังอยู่ที่คน ไม่ได้อยู่ที่เครื่องมือ
3. ต้องแยกแยะประเภทข้อมูลให้ชัดก่อนตัดสินใจว่าใส่เข้า Cowork ได้หรือไม่ ผมเสนอเฟรมเวิร์ค 3 ชั้นสำหรับข้าราชการแบบนี้ 
ชั้นเขียว คือข้อมูลสาธารณะที่เผยแพร่ทั่วไปแล้ว เช่น กฎหมาย ระเบียบ ประกาศ คู่มือประชาชน ข่าวประชาสัมพันธ์ ใส่เข้า Cowork ได้ทันทีไม่ต้องคิดมาก 
ชั้นเหลือง คือข้อมูลภายในที่ยังไม่เป็นข้อมูลส่วนบุคคล เช่น ร่างหนังสือ บันทึกประชุม รายงานภายใน แผนงาน ข้อมูลเชิงสถิติที่ไม่ระบุตัวบุคคล ใส่เข้า Cowork ได้แต่ภายใต้ความระมัดระวังสูงสุด ควรกรองข้อมูลที่ระบุตัวตนออกทั้งหมดก่อน และระวังไม่ให้หลุดข้อมูลที่เป็นความลับของทางราชการ 
ชั้นแดง คือข้อมูลส่วนบุคคลของประชาชน ข้อมูลความมั่นคง ข้อมูลความลับของทางราชการ ห้ามใส่เข้า Cowork โดยเด็ดขาด ไม่ว่าจะแพลนใดก็ตาม ข้อมูลพวกนี้ต้องอยู่ในระบบปิดของหน่วยงานเท่านั้น
ก่อนเริ่มทุก task ให้ถามตัวเองสัก 10 วินาทีว่าไฟล์นี้อยู่ชั้นไหน ถ้าตอบไม่ได้แปลว่ายังไม่ควรใส่เข้า Cowork ครับ
.
Claude Cowork มาช่วยให้ข้าราชการมีเวลาคิดงานเชิงนโยบายมากขึ้น มีเวลาบริการประชาชนเต็มที่ และทำงานเอกสารด้วยความเครียดน้อยลงได้
ถ้าใครอ่านมาถึงตรงนี้แล้วอยากเรียนรู้การใช้ Claude Cowork แบบลงมือทำจริง พร้อมเซ็ตอัป Project Skills, Connectors และ Scheduled Tasks ของตัวเองในห้องเรียน
